# 智学网浏览器阅卷经验

这是操作经验，不是替代当前浏览器工具文档的API规范。先读取当次可用工具返回的文档；只使用其支持的接口和已观察到的页面元素。

## 连接与登录

- 教师可能已在Edge登录。先检查当前工具能否读取该窗口或浏览器标签。若工具明确停止并禁止后续操作，遵守停止要求；不要在同一轮用其他方式绕过限制。
- 若用户同意切换内部浏览器，打开其提供的阅卷链接。内部浏览器通常有独立登录态；登录页不代表用户原来的Edge未登录。让用户在内部浏览器完成扫码或登录，随后检查标签列表，绑定真正的“个人阅卷”标签，不一直停在教师首页。
- 超时后先检查标签是否已创建或动作是否完成，不重复新建标签或提交。只有句柄丢失或过期时重新获取。
- 不在skill中硬编码考试链接、markingPaperId、教师账号或带token的返回任务列表链接。

## 当前页面需观察的信息

- 考试名称、题号、题目切换入口及任务范围。
- “初评已阅量/任务量”和当前分数。历史上出现“共2题”与“第76题”并存，不能据此认定两个题都要批。
- 待评与回评模式：“继续阅卷”“回评上一份”“回评下一份”。
- 输入框标注的满分、打分步长、“自动提交”状态、提交按钮及问题卷入口。

若DOM可读取，优先使用稳定的语义定位。一次页面曾暴露 `getByRole('textbox', {name: '满分25'})` 与 `getByRole('button', {name: '提交分数', exact: true})`，但名称和分值必须以当次快照为准。先读完当前文章，再填写其分数并执行一次必要的提交动作。

## 校准历史样本

“阅卷记录”面板可能提供分数筛选和记录列表。点击记录后先观察是否进入回评；此时不修改老师的历史分数。面板可能遮住正文，关闭入口也可能直接退出回评并返回待评卷，因此关闭后必须重新核对文章，不能沿用刚才样本的判断。

需要修改刚提交的一篇时，可尝试当前页面的“回评上一份”，但必须对照全文确认确为目标文章。回评提交可能出现“当前试卷已回评结束，是否继续阅卷？”等提示，根据实际按钮语义返回待评队列。回评分数保存不应被算作新增阅卷量。

## 完整阅读图片

- `fullPage`截图通常只覆盖页面本身，不会自动展开内部答卷滚动区。看见两张图片不等于读完第二张底部。
- 优先读取当前页面答卷原尺寸图片，或使用当前工具支持的图片资源能力。不要扫描浏览器缓存、调用网站隐藏API或批量抓取未在页面显示的学生答卷。
- 一次页面的可见答卷位于 `#imgBox img`，在DOM观察确认后可只读取此区域的图片。先检查来源：可能是data URL，也可能是远程签名URL；两者的读取办法不能混用。
- data URL在某些工具序列化时会截断长字符串，导致“invalid base64 data URL”。若当前工具允许读取DOM图像，可将当前可见图片的src按小段返回，在工具会话中拼接后用图片显示接口查看；不要把base64输出为文本。
- 远程图片使用工具支持的页面资源导出或媒体下载能力。资源目录与当前DOM图像不匹配时，不凭历史资源顺序猜是哪篇，不自行构造签名地址。
- 缩放、增强或滚动后重新观察。网页或侧栏尺寸变化会导致截图横向裁切，不能因裁切误判作文缺少内容。
- 清晰度增强并不总更好；可对照开关前后的真实效果。读不清的情况按待处理流程处理，不能用低分代替图像问题。

## 可靠提交与进度

- 一篇只提交一次；自动提交开启时，不再追加一次手动提交。
- 超时或断连后结果未知，先观察进度、分数或回评记录，再决定是否需要重试。
- 进度跳过多份可能来自教师在其他标签或浏览器同步提交，不能直接认定为重复提交，也不能直接继续。先停写并确认独立操作权，再核对当前待评文章。
- 全部结束时读取页面成功提示、任务状态和最终计数，核对问题卷或未完成项。只有实际确认后才报告“全部批完”。教师宣布完成并要求总结时停止操作，基于已读文章给反馈。
- 在工具要求的情况下保存最终页面截图并提供可查看证据；只保留任务所需的最少本地材料，不将学生信息或会话凭据加入公开skill包。
